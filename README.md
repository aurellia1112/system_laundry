# 🧺 Laundry Management System

Aplikasi **Laundry Management System** merupakan sistem berbasis web yang dikembangkan menggunakan Laravel untuk membantu pengelolaan operasional usaha laundry secara lebih terstruktur, efektif, dan efisien.

## 📌 Tentang Project

Project ini dikembangkan untuk mendukung proses pengelolaan usaha laundry melalui aplikasi berbasis web.

**Repository:** [system_laundry](https://github.com/aurellia1112/system_laundry)

## 🛠️ Teknologi yang Digunakan

| Teknologi | Keterangan |
|---|---|
| PHP | 8.3 atau lebih baru |
| Laravel | 13 |
| JavaScript | Interaktivitas frontend |
| Vite | Asset bundling |
| Tailwind CSS | Styling antarmuka |
| Alpine.js | Interaktivitas frontend |
| Composer | PHP dependency manager |
| NPM | JavaScript package manager |

## ✨ Fitur Aplikasi

Sistem ini ditujukan untuk membantu pengelolaan aktivitas laundry. Fitur yang tersedia dapat disesuaikan dengan implementasi aplikasi, seperti:

- Pengelolaan data pelanggan.
- Pengelolaan transaksi laundry.
- Pengelolaan data layanan laundry.
- Pemantauan status pesanan.
- Pengelolaan data operasional.

## 📋 Persyaratan Sistem

Pastikan perangkat sudah memiliki:

- PHP >= 8.3
- Composer
- Node.js dan NPM
- Database MySQL atau database lain yang didukung Laravel
- Git

## 🚀 Instalasi dan Menjalankan Project

### 1. Clone Repository

```bash
git clone https://github.com/aurellia1112/system_laundry.git
```

### 2. Masuk ke Folder Project

```bash
cd system_laundry
```

### 3. Install Dependency Laravel

```bash
composer install
```

### 4. Konfigurasi Environment

Salin file `.env.example` menjadi `.env`.

```bash
cp .env.example .env
```

### 5. Generate Application Key

```bash
php artisan key:generate
```

### 6. Konfigurasi Database

Buka file `.env`, kemudian sesuaikan konfigurasi
